# Resolved: Hero Demo C Major vs A Minor Center

**Status:** Resolved / Case Closed (2026-08-23)

## The Question

In refining the homepage hero demo (the opening phrase of the Beatles' *Yesterday*, transposed from F Major to fit on a C4–C5 mini keyboard), a question arose: should the map's center be treated as **C Major** or **A Minor**?

Since the progression briefly visits the relative minor, we considered whether the map should center on **A** instead of **C** to accurately reflect the harmony.

## The Analysis

The original song is in **F Major**. It was transposed up a perfect fifth to fit the keyboard, which puts it in **C Major**.

The chord progression of the phrase is:
`C` → `Bm7(b5)` → `E7` → `Am` → `G` → `F` → `G7` → `C`

While it does use a classic "ii-V-i" progression (`Bm7(b5)` → `E7` → `Am`) to momentarily resolve into the relative minor (A minor), the phrase immediately walks back down (`G` → `F` → `G7`) and definitively resolves back to home base on **C Major**.

## Conclusion

The phrase both begins and clearly resolves in **C Major**. Leaving the interactive map centered on C is musically correct and accurately reflects the overarching tonality of the demo song.

No changes were needed to the map's center or the app's default scale.
