# Archived plans

Finished plans live here so `docs/plans/` stays the work queue.

Move a plan here only when the **requested work is shipped** (parked
follow-ons are fine; open phases are not). Update `ToDo.md` in the same
change: drop the row from the active inventory and add it under
Archived.

A separate resolved-note folder exists at `docs/archive/` (decided
questions, not build plans).
